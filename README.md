# Arc Flash Engineering Calculator — Public Static Mirror

This repository serves an independently hosted browser mirror of the Arc Flash Engineering Calculator. It is published only to provide a reliable browser entry point while the custom `earcsafe.com` DNS path is remediated.

The published application retains the controlled nine-step AC/DC workflow, local draft persistence, device-local Job Archive, local PDF generation, bundled reference metadata, technician Help, and multilingual user interface. The static mirror does **not** expose a server-side service. Accordingly, the hosted Arc Flash Assistant is unavailable on this mirror and no calculation, archive, or report data is sent to GitHub Pages.

> **Safety boundary:** Calculator output is a controlled engineering aid. It does not approve energised work, assign final PPE, determine clearing time automatically, or replace qualified engineering review and field verification.

The production contents in this repository are generated deployment artifacts. The application is published from the `main` branch through GitHub Pages.
